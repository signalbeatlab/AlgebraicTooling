# AlgebraicTooling

This repository is an auxiliary workspace for analyzing, testing, and documenting tools that are backed by algebra.

## Folders

* **[`StockFlow-demos`](./StockFlow-demos)** — Small standalone scripts for demonstrating compositional stock-and-flow modeling with StockFlow.jl.
